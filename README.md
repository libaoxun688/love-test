🧠 依恋类型诊断 — 你的爱情"出厂设置"
基于 Brennan 等人的 ECR（亲密关系经历量表），从"焦虑度"和"回避度"两个维度，判定你的依恋类型：

安全型 — 能亲密也能独立，关系中游刃有余
** preoccupied（痴迷型）** — 渴望亲密，害怕被抛弃
dismissive（疏离型） — 习惯独立，回避深度亲密
fearful（恐惧型） — 渴望又害怕，反复拉扯
36 题标准版 / 12 题快速版 / 24 题均衡版，三档可选按需匹配。

你得到的不只是一个标签 — 还有针对性的成长建议，告诉你安全型是如何思考的，非安全型可以怎样调整。

🔺 爱情三元论 — 你的爱情三角形是什么形状？
斯滕伯格说爱情由三个要素组成：亲密（情感连接）、激情（生理吸引）、承诺（维持关系的决定）。

45 题标准版精确测量三个维度的得分，15 题快速版快速定位。结果页用三维雷达图可视化你的爱情三角形形状——

等边三角形 → 完美爱情
缺角三角形 → 某维度不足
扁平三角形 → 某维度特别突出
不同类型的爱情三角形，对应着不同的关系模式。

🎨 爱情色彩风格 — 你用哪种颜色去爱？
Lee 将爱情比作色彩，提出六种风格。你是哪种？

Eros（ eros 式） — 热烈浪漫，一见钟情
Ludus（游戏式） — 轻松随性，享受过程
Storge（友谊式） — 从朋友变恋人，细水长流
Pragma（务实式） — 理性匹配，条件优先
Mania（占有式） — 患得患失，爱得浓烈
Agape（奉献式） — 无条件付出，成就对方
42 题标准版 / 24 题快速版。结果页展示你的主导风格和次要风格，并告诉你不同风格组合在关系中会擦出什么火花。

Chapman 说每个人表达和接收爱的方式不同。你是哪种？
